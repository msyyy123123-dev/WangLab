Marry

Undergraduate Student

专业：植物保护 (Plant Protection)

年级：本科三年级

Biography

Marry 现为中国农业大学植物保护专业本科三年级学生，对昆虫学、植物病理学与计算生物学的交叉领域具有浓厚兴趣。在 WangLab 期间，主要参与大蚕蛾科的系统发育分析、昆虫形态学观察以及农业智慧诊断平台的开发与维护工作。

Research Experience

  • 蛾类基因组学与系统发育分析：
    在 Linux 服务器环境下独立配置生信分析环境，使用 Mafft、IQ-TREE 等工具对大蚕蛾 CO1 基因进行多序列比对及最大似然系统发育树构建，并通过 iTOL 进行可视化渲染。
  • 昆虫形态学与干湿实验基础：
    参与昆虫网捕采集、标本制作与室内饲养观察，重点关注华尾大蚕蛾、绿尾大蚕蛾等物种的口器退化特征。顺利完成涿州野外实习。
  • 农业病害智能诊断工具开发：
    主导开发小麦病害智能诊断网站，设计基于症状和农药选择的匹配逻辑；搭建并维护“农声论坛”及 WangLab 官方网站。

Skills

  • Bioinformatics: Linux Shell, Mafft, IQ-TREE, iTOL
  • Web Development: HTML/CSS, Bootstrap, Web Server Deployment
  • Lab Skills: Insect Rearing, Specimen Preparation, Morphological Observation
